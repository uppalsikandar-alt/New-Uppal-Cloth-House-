# New Uppal Cloth House

Website for **New Uppal Cloth House** (Est. 1987) – premium unstitched men's fabrics.
Proprietor: Saif Ullah Uppal · 0303 7475767

## Files
- `index.html` – the whole website
- `images/` – all website photos (keep this folder next to `index.html`)

## Put it online with GitHub Pages
1. Upload everything in this folder to a GitHub repository (`index.html` must be at the top level, not inside another folder).
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select branch **main** and folder **/ (root)**, then **Save**.
4. After a minute your site will be live at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.
